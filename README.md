# Monster Truck Hunter

**Monster Truck Hunter** is a cooperative 1-to-4-player split-screen boss battler where every character is a vehicle. Play as either a tank, ambulance, fire truck, or taxi and hunt down the massive monster truck with your bubble guns.

**Official Game Jam Page:**  
[https://globalgamejam.org/games/2025/monster-truck-hunter-9](https://globalgamejam.org/games/2025/monster-truck-hunter-9)

## Controls

### Player 1 – Keyboard

#### Menu
- **W** – Join game
- **S** – Leave game
- **Space** – Start game

#### Driving
- **W** – Accelerate
- **S** – Brake/Reverse
- **A** – Steer left
- **D** – Steer right
- **E** – Fire bubble gun
- **F** – Fire bubble mortar
- **Tab** – Change view

---

### Players 2-4 – Xbox Controller

#### Menu
- **D-pad Up** – Join game
- **D-pad Down** – Leave game
- **A** – Start game

#### Driving
- **Right Trigger** – Accelerate
- **Left Trigger** – Brake/Reverse
- **Left Joystick** – Steer left/right
- **Right Bumper** – Fire bubble gun
- **Left Bumper** – Fire bubble mortar
- **Y** – Change view
